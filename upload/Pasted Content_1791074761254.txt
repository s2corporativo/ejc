# 1. PRINCÍPIOS INEGOCIÁVEIS

Implemente estas regras como invariantes de backend, não apenas como instruções de prompt.

1. IA nunca cria fato automaticamente confirmado.
2. IA nunca confirma prazo.
3. IA nunca aprova tese.
4. IA nunca cria jurisprudência, lei, número de processo ou fonte inexistente.
5. Todo fato relevante deve apontar para evidência.
6. Evidência deve pertencer ao mesmo caso.
7. Um modelo não pode inventar `evidence_ref_id`.
8. Saída de IA começa sempre como `candidate`.
9. Confirmação jurídica depende de revisão humana.
10. Provider externo nunca recebe PII real quando política exigir pseudonimização.
11. Caso marcado `local_only` nunca pode ser enviado a provider externo.
12. Na ausência de provider local elegível para caso `local_only`, falhar fechado.
13. Toda execução de IA deve possuir `AgentRun`.
14. Toda chamada de modelo deve passar pelo `AI Gateway`.
15. Nenhum service jurídico chama SDK OpenAI, Anthropic, Groq, Maritaca etc. diretamente.
16. Toda execução deve registrar provider, modelo, tokens, custo, duração e versão do contrato utilizado.
17. Não registrar OCR integral, prompt integral com PII ou respostas sensíveis em logs.
18. Falha do LLM nunca deve destruir o resultado determinístico.
19. Banco do sistema é a fonte da verdade.
20. Ferramentas externas apenas enriquecem o sistema.

# 6. HASH DA EVIDÊNCIA

Implemente:

```python
import hashlib
import re


def normalize_quote(text: str) -> str:
    return re.sub(r"\s+", " ", text or "").strip()


def quote_hash(text: str) -> str:
    normalized = normalize_quote(text)

    if not normalized:
        raise ValueError("Evidence quote cannot be empty")

    return hashlib.sha256(
        normalized.encode("utf-8")
    ).hexdigest()
```

# 7. EVIDENCE SERVICE

Crie obrigatoriamente verificação de ownership.

```python
async def create_evidence(
    db,
    *,
    case_id: str,
    document_id: str,
    quote: str,
    page_number: int | None,
    source_kind: str,
    retrieval_method: str,
    actor,
):
    await verify_case_access(
        db,
        actor,
        case_id,
    )

    document = await get_document(
        db,
        document_id,
    )

    if not document:
        raise NotFoundError(
            "Documento não encontrado"
        )

    if str(document.case_id) != str(case_id):
        raise ForbiddenError(
            "Documento não pertence ao caso"
        )

    normalized = normalize_quote(
        quote
    )

    if not normalized:
        raise ValueError(
            "Trecho vazio"
        )

    qhash = quote_hash(
        normalized
    )

    existing = await find_existing_evidence(
        db,
        case_id=case_id,
        document_id=document_id,
        page_number=page_number,
        quote_hash=qhash,
    )

    if existing:
        return existing

    evidence = EvidenceRef(
        id=new_uuid(),
        case_id=case_id,
        document_id=document_id,
        page_number=page_number,
        quote=normalized,
        quote_hash=qhash,
        document_hash=document.sha256,
        source_kind=source_kind,
        retrieval_method=retrieval_method,
    )

    db.add(evidence)

    await db.commit()
    await db.refresh(evidence)

    return evidence
```

# 22. PSEUDONIMIZAÇÃO

Crie um mapa efêmero por execução:

```python
@dataclass
class PseudonymMap:

    forward: dict[str, str]

    reverse: dict[str, str]


def pseudonymize_entities(
    text: str,
    entities: list[str],
) -> tuple[str, PseudonymMap]:

    forward = {}
    reverse = {}

    output = text

    for index, value in enumerate(
        sorted(
            set(entities),
            key=len,
            reverse=True,
        ),
        start=1,
    ):
        token = f"[ENTIDADE_{index}]"

        forward[value] = token
        reverse[token] = value

        output = output.replace(
            value,
            token,
        )

    return (
        output,
        PseudonymMap(
            forward=forward,
            reverse=reverse,
        ),
    )
```

O mapa de reidratação:

- não vai para o provider;
- não deve aparecer em logs;
- deve existir somente durante a execução quando possível.

async def validate_mapper_output(

# 51. OBJETIVO PRINCIPAL

O objetivo não é construir uma IA que simplesmente:

```text
"escreva uma petição"
```

O objetivo é construir um sistema capaz de explicar:

```text
O que aconteceu?

Qual documento demonstra isso?

Qual trecho demonstra isso?

Qual fato está confirmado?

Qual fato é apenas alegado?

Qual informação está faltando?

Quais fatos se contradizem?

Quais questões jurídicas surgem?

Quais provas seriam necessárias?

Qual legislação é aplicável?

Qual jurisprudência sustenta?

Qual jurisprudência contraria?

O precedente continua válido?

Qual tese é possível?

Qual risco existe?

O que é fato?

O que é inferência?

O que foi produzido pela IA?

O que foi validado por um advogado?
```

Toda resposta relevante deverá ser rastreável.
