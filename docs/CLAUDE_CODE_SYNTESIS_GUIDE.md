# Guia de Síntese e Implantação — EJC v5.0 Fronteira Tecnológica

## 1. DNA Visual Law Total (Soberania Estética)
O EJC v5.0 exige que toda a interface e documentos sigam a estética **Bronze & Elegance**.
- **Logomarca:** Integrada em todos os cabeçalhos de PDF e na interface.
- **Tipografia:** `Libre Baskerville` (Serifada) e `Inter` (Sans-serif).
- **Componentes:** Use `premium-card` e gradientes metálicos.

## 2. Novas Camadas de Inteligência v5.0
- **App Mobile de Alertas:** Notificações via WebSockets/Firebase para Radar de Poder.
- **Robôs RPA:** Automação de protocolos burocráticos integrada.
- **Portal de Mediação:** Ambiente de negociação inteligente com algoritmo de VPL/Selic.
- **Auditor de Honorários:** Localizador de ativos ocultos em processos encerrados.
- **Memoriais em Vídeo:** Sustentação oral via QR Code em petições.

## 3. Auditoria DevOps & Docker (Anexo 14)
Você atua como Arquiteto-Executor. Analise, corrija e implemente.
1. **Ajuste de Permissões:** `sudo chown -R 1000:1000 /opt/ejc/`.
2. **Build do Frontend:** `npm run build` deve processar os novos estilos de luxo.
3. **Deploy:** `docker compose up -d --build`.
