# Wave 3 — FE-01, FE-02, FE-03, FE-05 e FE-06

## Resultado executivo

A auditoria confirmou que os cinco arquivos candidatos de FE-01/02/03 já não existem na árvore frontend da branch: `ConteudoJuridico.tsx`, `DashboardAiChat.tsx`, `CaseClosureModal.tsx`, `DeadlineRiskStrip.tsx` e `JurisprudentialAlertsStrip.tsx`. Também não foram encontrados importadores ou testes ativos para esses nomes. Em vez de executar uma remoção vazia, foi adicionado um contrato anti-retorno que falha se os arquivos ou referências forem reintroduzidos.

FE-05 e FE-06 foram implementados. `LoginModern.tsx` foi renomeado para `Login.tsx` e passou a ser carregado com `lazy()`. `EntradaUniversalGlobal`, `FlowEnhancements` e `PortalLayout` também passaram a ser imports lazy. Todos permanecem sob o `Suspense` global já existente no `App`, portanto a mudança não introduz uma superfície de loading sem fallback.

## FE-01/02/03 — limpeza estrutural

Os itens foram reconciliados como já ausentes na branch atual. A integridade foi protegida por `wave3Frontend.contract.test.ts`, que verifica a ausência dos arquivos e pesquisa referências em todo o código TypeScript/TSX do frontend.

Não foram apagados arquivos existentes nem removidos componentes que possuam consumidores indiretos. Essa decisão evita uma alteração destrutiva baseada apenas em backlog desatualizado.

## FE-05 — Login

O caminho canônico passou a ser `frontend/src/pages/Login.tsx`. O `App.tsx` usa `lazy(() => import("./pages/Login"))`, removendo o login do bundle eager inicial sem mudar a rota pública `/login`.

## FE-06 — superfícies globais

O `App.tsx` deixou de importar eager `PortalLayout`, `EntradaUniversalGlobal` e `FlowEnhancements`. Cada módulo agora é carregado sob demanda e utiliza o fallback `RouteFallback` do `Suspense` que envolve as rotas.

## Validação

Foi adicionado contrato Vitest para a limpeza e o carregamento lazy. A validação final deve executar `npm run build`, o contrato Wave 3, `npm test -- --run` e os testes de navegação/rotas quando houver backend e browser disponíveis.

## Rollback

A mudança é reversível: restaurar `LoginModern.tsx`, recolocar os imports estáticos em `App.tsx` e remover o contrato Wave 3. Nenhuma rota, API ou contrato de negócio foi alterado.
