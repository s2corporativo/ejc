# Arquivo de relatórios históricos

Relatórios, planos, laudos e auditorias pontuais de fases anteriores do EJC,
movidos da raiz do repositório para reduzir o ruído. São documentos de
referência histórica (não operacionais); o histórico de git foi preservado
via `git mv`.

Documentação **operacional/atual** vive na raiz (`README.md`, `RUNBOOK_*.md`)
e em `docs/` (fora de `archive/`).
